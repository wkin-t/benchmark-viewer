# 补充视图的细节与图上必须出现的说明文字

## Question

工单 03 留下三个细节，都属于"图上写什么"：

1. 补充视图是否也画 Pareto 前沿线和预算档小表？（补充视图只有单价一个 X 轴，没有档位连线。）
2. 官方成本的计价口径未验证（GLM-5.3 官方成本非零，而 BenchLM 单价为 0）：图上如何提示"成本口径未验证，不同厂商可能不可比"？放在哪里、措辞是什么？
3. 页脚署名与免责的最终清单和版式（数据截止时间的展示归工单 08，此处只需为它留位置）：BenchLM 署名（文案见工单 02）、官方榜单来源（见工单 06）、AA 口径提示、成本口径提示、"分数接近的行在误差范围内"、无价格模型排除数、地区不做筛选的说明是否需要。

产出：图上所有说明文字的位置、触发条件和措辞清单，可直接写进 spec。
调用 `/grilling` 与 `/domain-modeling`。

## Answer

用户于 2026-09-29 逐项确认。页面上对读者展示的名称统一为**"最优前沿"**（术语 Pareto 前沿），并配一句解释，不要求读者懂这个词。

**补充视图的最优前沿**：补充视图**只画最优前沿线，不做预算档小表**。前沿按单价计算，线旁注明"最优前沿（按单价）"；预算档的定义是每任务成本区间，用单价套会混淆口径。

**官方成本口径提示**：放在官方视图 X 轴标题旁的 ⓘ 图标（悬停显示），不在个别"异常点"上单独标记（那是我们自己的推断，不做）。

**依据**：官方每行 95% 置信区间半宽在 ±2.45 到 ±3.94 个百分点之间，榜首几行差距小于误差；GLM-5.3 官方总成本 $2,727.63、总 token 约 86.8 亿（折算约每百万 token $0.31），而 BenchLM 单价为 0，两个口径不可混用。官方榜单前沿（成本从低到高）：GPT-5.6 Luna max（$1.05，17.27%）、GPT-6 Astra low（$4.72，50.61%）、medium（$5.80，54.24%）、high（$6.88，57.88%）、max（$9.90，58.18%）。

**图上说明文字最终清单**

官方视图：
- A1 顶部信息行：见工单 08。
- A2 X 轴标题"平均每任务成本（美元，实测）ⓘ"，悬停：**"成本 = 官方榜单公布的该行 330 次试验总成本 ÷ 330。官方未说明计价口径（是否按公开单价、是否含缓存折扣），不同厂商之间可能不完全可比。每一行是'模型 + 框架 + 档位'的整套结果，不是模型单价。"** 其中 330 取自数据的 `n_trials`。
- A3 Y 轴标题："Terminal-Bench 4.0 分数（任务完成率）"。
- A4 图下注：**"分数接近的行在统计上分不出高下：每行有 95% 置信区间（悬停查看），约 ±<最小值> 到 ±<最大值> 个百分点。"** 数字取当前数据的最小与最大半宽，不写死。
- A5 前沿线图例：**"最优前沿：没有'成本更低且分数更高'的行"**。
- A6 图下注：**"官方榜单只收录维护者评测过的模型；未收录的（如 DeepSeek、Qwen、Kimi）请看「补充」视图。"**

补充视图：
- B1 顶部横幅（常驻）：**"分数来自 Artificial Analysis 的独立评测（经 BenchLM 数据集提供），评测设置与官方榜单不同，不可与官方视图直接比较。"**
- B2 X 轴标题："输出单价（美元 / 百万 token，不是每任务成本）"。
- B3 前沿线旁："最优前沿（按单价）"。
- B4 图例：**"◆ 官方榜单也收录了此模型（这里的分数来自另一套评测）"**。
- B5 图下注：**"已排除 N 个无公开价格的模型"**，悬停显示名单，N 取实际值。
- B6 顶部信息行：BenchLM 快照日期和上次同步时间。

页脚（两个视图共用）：
- F1：**"数据来源：Terminal-Bench 4.0 官方榜单（Harbor Hub，含链接）及方法说明；模型价格、发布信息与 Artificial Analysis 分数：Data from BenchLM.ai（含链接），许可 CC BY-NC 4.0（含链接）。本页对成本做了计算（总成本 ÷ 试验次数）并转换了格式。仅限非商业、内部使用。"**
- F2："本页为内部参考工具，与上述数据提供方无隶属关系。"

**不需要的**：地区说明（已决定不做地区筛选）、模型映射缺失的全局提示。

**简化发现**：官方每行自带发布日期，成本也来自官方，所以官方视图不需要 BenchLM 的价格和映射表。映射表（15 项）只用于补充视图的 ◆ 标记；映射缺失时静默不标记，并在浏览器控制台记一条警告。这一点修正了工单 04 的答案里"映射不上的新模型不带价格并提示"的说法：该说法只适用于补充视图，且不再弹出页面提示。


## 修订（2026-09-29，实现前红军审查后）

官方视图的覆盖说明（A6）：夹具核对发现 Qwen（`qwen3-8-27b`）和 GLM-5.3 在补充视图里因无价格被排除，原文案"如 DeepSeek、Qwen、Kimi 请看补充视图"会误导。改为：**"官方榜单只收录维护者评测过的模型；未收录且有公开价格的（如 DeepSeek、Kimi、MiniMax）请看「补充」视图。无公开价格的开源或自托管模型（如 Qwen、GLM 的部分型号）两个视图都无法绘制。"** 以 `spec.md` 为准。
