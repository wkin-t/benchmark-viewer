# 做哪几张图？每张图的 X/Y 和口径是什么？

## Question

基于 01 核实过的字段，与用户敲定视图清单：

- 价格视图（主）：X=输出单价（对数轴）、Y=Terminal-Bench 分数、Pareto 前沿。
- 综合视图：Y 用哪个综合分（BenchLM 总分 / Agentic 类别分 / 其他），X 用什么。
- 是否加速度、上下文、发布时间视图；视图之间如何切换。
- 同一模型多个推理档位：默认"只显示最佳档"还是全显示（参考 DeepSWE 的 Best/All）。
- Pareto 前沿的定义（单价低且分数高的非支配点）和"每个价位最好模型"的表述。

产出：视图清单，每张图的轴、口径、默认设置和图上必须出现的注释。
调用 `/grilling` 与 `/domain-modeling`；术语（价格 / 成本 / 配置 / 档位）记入 `CONTEXT.md`。

## Answer

用户于 2026-09-29 逐项确认：

**视图结构**
1. 顶层切换数据源：**官方榜单 | 补充（Artificial Analysis）**。
2. 官方榜单为主视图，Y 轴是官方 Terminal-Bench 4.0 分数；X 轴可在 **成本 | 输出 token | 耗时** 间切换，默认成本。三项均为每次试验平均值、实测。
3. 补充视图：Y 轴是 AA 的 Terminal-Bench 4.0 分数，X 轴只有 BenchLM 输出单价（价格，不是成本）。收 20 个有价格的模型；与官方榜单重合的 7 个用不同形状标记并注明分数来自另一套评测、不可直接对比；无价格的 5 个不画，图注写明排除数量。

**样式（与 DeepSWE 基本一致）**：X 轴反向（越便宜越靠右）；官方视图中同模型的档位同色系深浅连线；标签为"模型名 + 小字档位"；深浅色主题切换；Configs 筛选下拉（按模型勾选、档位小按钮、无数据档位划掉、Select all / Clear、"x/y"计数）；不做版本切换。

**点的粒度**：默认每个榜单行一个点（27 点），可切换为每模型只取最佳档（15 点）。

**不确定性与最优**：悬停显示分数 ± 95% 置信区间，默认不画误差线，图注写明"分数接近的行在统计上分不出高下"。图上画 Pareto 前沿线（前沿上的点加粗），图下加"预算档内最好的榜单行"小表（如 ≤$5、≤$10、≤$15），并列时并列显示。

**悬停内容**：官方视图显示模型、框架、档位、分数 ± 置信区间、成本、输出 token、耗时、发布日期；补充视图显示分数、单价、发布日期。

**默认状态**：官方榜单 · 成本，配置全选，主题跟随系统；顶部显示数据日期和来源链接；页脚署名（文案见工单 02 和 06）。

**不做**：地区筛选（只提供按厂商筛选）、步数指标（官方无该字段）、把两份分数混画在同一张图。

依据：官方接口有实测成本（工单 06）；官方榜单只收录维护者跑过的模型，中国厂商只有 GLM-5.3（Z.ai）一个，DeepSeek、Qwen、Kimi、MiniMax、小米等在官方榜单中没有，只能在补充视图里以 AA 分数出现。
